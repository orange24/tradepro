# คำตอบจาก NotebookLM (คลิปลุงโฉลก) 2 ต.ค. 2569

สรุปจากคำตอบ 14 ข้อที่ Boy ถาม NotebookLM (ข้อความเต็มอยู่ในเธรดของโปรเจกต์)

1. ฐาน Wave 1 = จุดต่ำสุดที่ไม่ทำ new low อีก ยืนยันด้วยเขียวแรก ไม่มีตัวเลขขั้นต่ำของขา W1, แมงเม่าช่วยยืนยันแต่ไม่บังคับ
2. Timeframe: Daily ขึ้นไป (Day, 3-Day, Weekly, Monthly) ไม่บังคับให้ timeframe ใหญ่เขียวก่อน
3. ไม่ต้องรอ SET Index เขียว หุ้นรายตัว ~5% เขียวแรกนำ SET ได้
4. ไม่มีตัวเลขว่าเขียวหลังปลาย W2 นานแค่ไหน เขียวก่อนลงถึงกล่อง = ไม่เข้า (ยกเว้นบัญชีเก็งกำไร) ถ้าย่อตื้นแล้วทำ new high เหนือ W1 = Running Flat
5. Stop ใช้ "ราคาปิด" ใต้ปลาย W2 (แคบ) หรือใต้ฐาน W1 (ปลอดภัยจากการสะบัด) ตามความเสี่ยงที่รับได้
6. ขาย 3 ไม้ที่ 161.8 / 261.8 / 423.6% หรือ 2 ไม้: ไม้แรกที่ 161.8% ไม้สองถือจน CDC แดง, CDC แดง = ปิด long ทันที, เลื่อน stop ด้วย ATR trailing หรือ previous low
7. ไม่มี time stop ถ้า CDC ยังเขียวและไม่หลุด stop ให้ "อยู่เฉย ๆ"
8. Running Flat: W2 ย่อไม่ถึงกล่อง, ขา B ทำ new high เหนือยอด W1 (Strong B), C ไม่หลุดฐาน W1, เข้าเมื่อ new high หรือเขียวแรกหลัง C, stop ปลาย C
9. แมงเม่า: จากกรอบแคบ (ATR ต่ำ) เกิด gap ลง + big black + ATR spike + volume สูง แล้วตามด้วย doji / hammer ไม่มีตัวเลข
10. เส้นแนวโน้มขาลง: trendline / channel / linear regression 2 SD จาก pivot high ไม่มีตัวเลข % ที่ต้องปิดเหนือ
11. CDC = EMA12 ตัด EMA26 ลุงสอนเฉพาะ เขียวซื้อ แดงขาย สีอื่นไม่พบคำอธิบาย
12. ไม่ใช้ปัจจัยพื้นฐาน กรองทั้งตลาดด้วยเงื่อนไขเทคนิค (เช่น MACD > 0, signal < 0) แล้วดูเวฟด้วยตา
13. Maximum Damage 1–10% ต่อเทรด, จำนวนหุ้น = เงินที่ยอมเสีย / (ราคาซื้อ − stop), ถือ ~10 ตัว (ไม่เกิน 10–20), 4 บัญชี 40 / 30–40 / 10–20 / 10%
14. โดน stop แล้วเข้าใหม่ได้ถ้ายังไม่ทำ new low หลุดโครงสร้าง และเกิดเขียวแรกรอบใหม่ ถ้าหลุดฐาน = นับเวฟใหม่
