# กลยุทธ์ Wave 3 + CDC Action Zone (แนวคิดลุงโฉลก ChalokeDotCom)

setup `W3` ในโปรแกรม: หาจังหวะที่ Wave 2 จบเพื่อเข้าเทรด Wave 3 โค้ดอยู่ที่ [`tradepro/wave.py`](../tradepro/wave.py)
ค่าตัวเลขปรับได้ใน `tradepro/config.py` (ตัวแปรขึ้นต้นด้วย `w3_`)

## กฎ

| รหัส | กฎของลุงโฉลก | ในโค้ด |
|---|---|---|
| W3-1 | หา Wave 1 ให้ชัด แล้ววัด Fibonacci จากฐาน Wave 1 ถึงยอด Wave 1 | ยอด W1 = swing high ล่าสุด (สูงสุดของ 5 แท่งซ้าย-ขวา `w3_pivot_bars`) ฐาน W1 = low ต่ำสุดใน 60 แท่งก่อนยอด (`w3_max_wave1_bars`) ขา W1 ต้องยาวอย่างน้อย 3 ATR (`w3_min_atr`) |
| W3-2 | Wave 2 ย่อลึก 61.8%, 78.6%, 88.7% (บางครั้ง 94.2%) โซนซื้อสำคัญ 78.6–88.7% | จุดต่ำสุดหลังยอด W1 ต้องย่อ 61.8–94.2% (`w3_retrace_min/max`) และไม่หลุดฐาน W1 ถ้าอยู่ในช่วง 78.6–88.7% จะมีคำว่า "sweet spot" ในหมายเหตุ |
| W3-3 | ยังไม่เขียว ยังไม่ซื้อ: รอ CDC Action Zone เขียวแรกบน Daily แล้วซื้อที่ราคาเปิดวันถัดไป | CDC Action Zone V3: AP = EMA2(OHLC4), Fast = EMA12(AP), Slow = EMA26(AP) เขียว = Fast > Slow และ AP > Fast สัญญาณเกิดบนแท่งแรกที่เปลี่ยนเป็นเขียว ภายใน 20 แท่งหลังจุดต่ำสุด W2 (`w3_max_bars_after_low`) และราคายังไม่เกินยอด W1 ซื้อที่ราคาเปิดวันถัดไป |
| W3-4 | Stop ที่ปลาย Wave 2 หรือจุดเริ่ม Wave 1 | 1 tick ใต้ปลาย Wave 2 |
| W3-5 | เป้า Fibonacci Extension จากฐาน W1 → ยอด W1 → ปลาย W2: 161.8%, 261.8%, 423.6% | เป้าแรก 161.8% ใช้ใน backtest ส่วน 261.8% และ 423.6% แสดงในหมายเหตุและเส้นบนกราฟ ถือได้นานสุด 120 วัน (`w3_max_hold_bars`) |
| W3-6 | หุ้นดีต้องมี R/R คุ้ม ตั้งแต่ 1:2 ขึ้นไป (stop แคบที่ปลาย W2 เป้า 161.8% อยู่ไกล) | reward/risk จากราคาปิดแท่งเขียวแรกถึงเป้า 161.8% ต้อง ≥ 2 (`w3_min_rr`) |
| W3-7 | สัญญาณยืนยันร่วม: breakout กรอบขาลง, runaway gap + big white, แมงเม่า panic sell ที่จุดต่ำสุด (gap ลง + big black หรือ ATR พุ่ง) | แสดงในหมายเหตุและการ์ดบนกราฟ ไม่ได้บังคับ: breakout = ปิดเหนือเส้นจากยอด W1 ผ่าน lower high สูงสุดใน W2, gap + big white = มีแท่ง gap ขึ้นที่เป็นแท่งเขียวใหญ่หลังปลาย W2, แมงเม่า = ภายใน 3 แท่งรอบปลาย W2 มี gap ลง + แท่งแดงใหญ่ หรือแท่งแดงที่ true range ≥ 2 เท่า ATR |
| W3-8 | ห้ามตกรถ: ราคาวิ่งไกลจากเขียวแรกจน stop ไกลเกินไปไม่ควรตาม | หน้าสแกนแสดง W3 ที่เขียวแรกภายใน 5 วัน (`w3_recent_bars`) ถ้า CDC ยังเขียว และ R/R จากราคาปิดล่าสุดยัง ≥ 2 |
| W3-9 | ห้ามรับมีด: หุ้นที่ยังทำ new low หาฐาน W1–W2 ไม่เจอ หรือ CDC ยังแดง | สัญญาณเกิดเฉพาะเมื่อ W2 ไม่หลุดฐาน W1 และบนแท่งเขียวแรกเท่านั้น |

การขาย (หน้าพอร์ต, `tradepro/advisor.py`):

| รหัส | กฎ | ในโค้ด |
|---|---|---|
| EXIT-5 | Lower high ร่วมกับ CDC ตัดเป็นแดง = จบอัพเทรนด์ | swing high ล่าสุดต่ำกว่าตัวก่อน + CDC แดง → **ควรขาย**, CDC แดงอย่างเดียว → **เฝ้าระวัง** |
| EXIT-6 | แมงเม่าไล่ราคาที่ยอดดอย (gap + big white ณ ราคาแพง) | gap ขึ้น + แท่งเขียวใหญ่ และราคาปิดสูงกว่า EMA20 เกิน 2.5 ATR → **เฝ้าระวัง** |

**ยังไม่ได้ทำ**: Running Flat (Wave 2 ย่อไม่ลึกในโครงสร้าง Wave 3 ใหญ่) และ Harmonic Pattern
เพราะการนับเวฟและรูปแบบพวกนี้ต้องใช้วิจารณญาณ เขียนเป็นกฎตายตัวได้ยาก EXIT-5 / EXIT-6 ยังไม่ได้ backtest

**ข้อควรรู้**: การนับเวฟของลุงโฉลกเป็นการมองด้วยตา โปรแกรมใช้ swing high / low แทน จึงอาจนับ Wave 1 ต่างจากที่คนนับ
ก่อนซื้อจริงควรเปิดกราฟดูว่า Wave 1 ที่โปรแกรมเลือก (เส้นม่วง "ฐาน W1" / "ยอด W1") ตรงกับที่คุณเห็นหรือไม่

## ผล backtest (30 ก.ย. 2569)

SET50 + US50 ตั้งแต่ 2015 ข้อมูล Yahoo หักค่าคอม (SET 0.2%, US 0.05%) ทดสอบ W3 แยกจาก setup อื่น

| กฎ | SET | US |
|---|---|---|
| W3 ไม่กรอง R/R | 295 เทรด, +0.07R | 377 เทรด, +0.28R |
| **W3 + R/R ≥ 1:2 (ค่าเริ่มต้น)** | **181 เทรด, ชนะ 34%, +0.19R, PF 1.29** | **256 เทรด, ชนะ 38%, +0.33R, PF 1.50** |
| R/R ≥ 1:3 | 61 เทรด, +0.50R | 118 เทรด, +0.37R |

ผลของสัญญาณยืนยัน (ในกลุ่ม R/R ≥ 2, "มี" เทียบ "ไม่มี"):

| สัญญาณ | SET | US |
|---|---|---|
| แมงเม่า panic sell ที่ปลาย W2 | +0.27R (45) vs +0.17R (136) | +0.47R (82) vs +0.27R (174) |
| breakout กรอบขาลง | +0.05R (107) vs +0.41R (74) | +0.22R (132) vs +0.45R (124) |
| runaway gap + big white | −0.41R (12) vs +0.24R (169) | +0.17R (32) vs +0.36R (224) |
| ย่อในโซน sweet spot 78.6–88.7% | −0.48R (18) vs +0.27R (163) | +0.09R (34) vs +0.37R (222) |

สรุป: R/R ≥ 1:2 ช่วยชัดเจนทั้งสองตลาด แมงเม่าที่ปลาย W2 เป็นสัญญาณยืนยันเดียวที่ดีขึ้นทั้งสองตลาด
ส่วน breakout กรอบขาลงและ gap + big white กลับแย่ลง น่าจะเพราะเมื่อเห็นสัญญาณพวกนี้ราคามักวิ่งขึ้นไปแล้ว ราคาเข้าจึงสูงขึ้น
sweet spot มีจำนวนเทรดน้อย ผลยังเชื่อไม่ได้ จึงแสดงเป็นข้อมูลเท่านั้น ไม่ได้ใช้กรอง
